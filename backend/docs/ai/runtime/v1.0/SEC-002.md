# SEC-002: Retrieval Policy & Isolation Review

## Keamanan Data di Era-2 (Retrieval Platform)
Di atas infrastruktur `AI Core Kernel`, akses terhadap rekam jejak (*Knowledge*) rentan akan intrusi jika sistem bertindak sekadar sebagai kotak pencari. Lapisan keamanan di AI-06 dikeraskan melalui dua pos:

### 1. Pre-Execution Validation (Workspace Isolation)
*Query Understanding Engine* memotong seluruh kueri yang tidak melampirkan parameter *Tenant* (`workspaceId`). Mustahil seorang pengelola *Workspace A* memanggil strategi untuk membaca data RKK dari *Workspace B*. (Pencapaian Isolasi 100%).

### 2. Post-Execution Validation (Policy Enforcer)
Setelah data *Vector/Graph* dimuntahkan oleh *Provider*, paket diinspeksi oleh penilai keamanan (*Evidence Validator*). Contoh: Data `Harga Vendor` yang terekstraksi oleh *Vector Similarity* akan diblokir apabila izin kebijakan pengguna tidak memadai.
- **Sensitive Data Leakage**: `NOL`. Seluruh data dipaketkan di bawah lisensi *Immutable Evidence*.
- **Otentikasi Manifest**: *Knowledge Package Manifest* akan diverifikasi keasliannya berbekal parameter keamanan komputasi enkripsi (`hash`), menggugurkan kecurigaan bahwa paket direkayasa oleh perantara (Man-in-the-Middle).
