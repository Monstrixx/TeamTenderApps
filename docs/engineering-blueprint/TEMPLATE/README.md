# Templates

This directory contains standard Markdown templates for use within the Engineering Blueprint.

- **[Volume.template.md](./Volume.template.md)**: Standard structure for a new Blueprint Volume.
- **[ADR.template.md](./ADR.template.md)**: Standard structure for Architecture Decision Records.
- **[RFC.template.md](./RFC.template.md)**: Standard structure for Requests for Comments.
- **[Review-Checklist.md](./Review-Checklist.md)**: Guidelines and checklist for reviewing new additions to the blueprint.
