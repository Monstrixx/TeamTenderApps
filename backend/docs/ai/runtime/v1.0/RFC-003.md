# RFC-003: Observation-Evaluation Loop

## Motivation
Selama ini rantai pikir LLM bertindak impulsif. Ketika menjumpai galat saat *Tool Call*, agen sering masuk ke dalam perangkap pengulangan (*Infinite Retry Loop*).

## Proposed Change (O-E-D-R)
1. **Observation (Sensor)**: *Agent Runtime* melahirkan mesin observasi yang tidak hanya mencatat "SUKSES/GAGAL". Melainkan:
   - *Unexpected Behavior*
   - *Side Effects*
   - *Confidence / Quality of capability result*
2. **Evaluation (Judge)**: Penilai terpisah mengevaluasi catatan *Observation* melawan kebijakan baku (*Evaluation Policy Registry*).
3. **Decision & Replan**: Jika evaluasi berujung *Threshold Not Met*, barulah sinyal dilempar kembali ke kotak surat Agen untuk fase `REPLANNING`.
