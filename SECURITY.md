# Security Policy

## Supported Versions

| Version | Supported |
| ------- | ------------------ |
| v1.0.0-rc1 | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability

Security is paramount to TeamTender Enterprise Platform.

If you discover a security vulnerability or potential credential leak:
1. **DO NOT** create a public GitHub Issue.
2. Email security reports directly to `security@teamtender.app` or contact the repository maintainers privately.
3. Include detailed steps to reproduce the vulnerability.

We aim to respond to security reports within 24 hours and issue patches via isolated hotfix branches.
