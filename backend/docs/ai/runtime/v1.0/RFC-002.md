# RFC-002: Retrieval Evolution

## Tujuan
Dokumen RFC ini menetapkan panduan evolusioner bagi lapisan **Retrieval Platform** dalam mengakuisisi bentuk data yang tidak umum, atau pergeseran paradigma mesin pencarian internal di tubuh *TeamTender AI*.

## Evolusi yang Direstui
### Penambahan Strategi (Strategy Injections)
*Plugin Domain* kelak diizinkan menambah mode pelacakan khusus via SDK. Misalnya:
- `SQLRetrievalStrategy`: Memungkinkan konversi kalimat (NLU) ke SQL, dijalankan, dan diformat menjadi *Facts*.
- `CAD/BIMRetrievalStrategy`: Ekstraksi struktur bangunan tiga dimensi untuk pelaporan kognitif *Tender*.

### Evolusi Indeks
Penambahan `IndexRegistry` tidak membutuhkan restu level CTO secara formal (Status `MINOR`), selama ekstensi tersebut mematuhi abstraksi `IRetriever` standar.

### Modifikasi Scoring
Penyesuaian bobot matematis untuk *Evidence Scoring* (seperti bobot kedaluwarsa atau *Freshness*) dapat dilakukan secara empiris dengan memonitor `Retrieval KPI Metrics` tanpa menunda rilis aplikasi.
