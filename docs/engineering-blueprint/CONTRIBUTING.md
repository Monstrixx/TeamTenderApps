# Contributing to the Engineering Blueprint

We welcome contributions to the Engineering Blueprint! 

## How to Contribute

1. **For small changes (typos, clarifications)**: Submit a Pull Request directly.
2. **For new architectural decisions**: Submit an [ADR](./ADR/README.md) using the [ADR Template](./TEMPLATE/ADR.template.md).
3. **For proposed changes requiring discussion**: Submit an [RFC](./RFC/README.md) using the [RFC Template](./TEMPLATE/RFC.template.md).
4. **When reviewing**: Please use the [Review Checklist](./TEMPLATE/Review-Checklist.md).
