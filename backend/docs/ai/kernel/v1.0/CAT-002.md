# CAT-002: Extension Point Catalog

Ekosistem TeamTender menganut paham *Plugin-First*. Tidak semua kebutuhan akan disediakan oleh sistem bawaan (Bawaan AI Core Kernel). Untuk itu, **AI Core Kernel** sengaja membongkar titik ekstensi (*Extension Points*) bagi pengembang pihak luar agar dapat menginjeksikan algoritma tambahan tanpa mengotori ruang `kernel/`.

## 1. Context Plugins
**Lokasi Injeksi**: `ContextComposer.ts`
**Deskripsi**: Anda dapat menambahkan modul pemasok data lokal (*Memory, Company Data, External Auth*) ke dalam rantai injeksi konteks. Modul baru harus mengimplementasikan fungsi `build(request: AIRequest, currentContext: any)`.

## 2. Mesh Middleware Policy
**Lokasi Injeksi**: `MiddlewarePipeline.ts` (pada rute `enforceMeshPolicy()`)
**Deskripsi**: Anda bisa menambahkan validator izin atau pembatasan pemanggilan (misal kuota *token*) per *tenant* (*workspace*).

## 3. Storage Adapters (Event Store / Bus)
**Lokasi Injeksi**: Implementasi `IEventStore` dan `IEventBus`
**Deskripsi**: Kernel mengandalkan MemoryStore saat evaluasi lokal. Anda diizinkan untuk membangun penyesuai koneksi (*adapters*) ke:
- Apache Kafka
- Redis Streams
- PostgreSQL Native Vector
- EventStoreDB

## 4. Projection Builders (CQRS)
**Lokasi Injeksi**: `ReplayEngine / ProjectionBuilder`
**Deskripsi**: Bagi pihak *Frontend* / Laporan Bisnis (*BI*) yang membutuhkan *Read Model* dengan agregat data harian, titik ini didesain agar *Event Store* sanggup di-ekstrak dan disintesis ke format *Snapshot* / Data Tabel konvensional secara aman tanpa *lock-in*.

## 5. Domain Plugin Registry
**Lokasi Injeksi**: `PluginSDK.register()`
**Deskripsi**: Titik masukan absolut di mana produk `Tender AI`, `Company AI`, dan kelak `Executive Copilot` mendaftarkan kapabilitasnya beserta perputaran nasib *manifest*-nya.
