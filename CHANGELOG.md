# Changelog

All notable changes to the TeamTender Enterprise Platform will be documented in this file.

## [v1.0.0-rc1] - 2026-07-28

### Status
🔒 **ARCHITECTURE FROZEN** (Era-1, Era-2, and Era-3 Certified & Locked)

### Platform Highlights
- **Workspace Runtime**: Multi-tenant workspace isolation and role management.
- **Company Platform**: Core company profiling, public presence, and experience layer.
- **Trust Platform**: Multi-layered audit log, evidence validation, and trust projection engines.
- **Knowledge Platform**: Universal entity graph and knowledge indexing (Era-1 Kernel).
- **Cognitive OS**: Stateful cognitive loop and working memory engine (Era-1 Kernel).
- **Service Mesh**: AI capability routing, tool registry, and execution mesh (Era-1 Kernel).
- **Event Platform**: Cognitive event store and pub/sub bus (Era-1 Kernel).
- **Retrieval Platform**: Knowledge Access Layer, immutable `KnowledgePackage`, and query fingerprinting (Era-2 Runtime).
- **Agent Runtime**: Actor-based distributed process manager (`AgentProcess`, `AgentMailbox`, `RuntimeScheduler`, O-E-D-R Loop) (Era-2 Runtime).
- **Plugin Platform**: Extensible Plugin OS (`PluginHost`, `PluginContainer`, `PluginSDK v1.0`, `PluginManifest v2.1`, Sandbox, Marketplace Governance) (Era-3 Platform).

- Officially completed Era-1 (Kernel), Era-2 (Runtime), and Era-3 (Plugin Platform).
