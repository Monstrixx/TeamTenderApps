# MTX-001: Dependency Matrix

## Arus Dependensi Modul Kernel
Matriks ini membuktikan validasi arah pengikatan (*Dependency Direction*) antar lapis komponen dalam **AI Core Kernel v1.0**. Komponen tidak diizinkan memanggil entitas melampaui batasan atasnya (*Upstream referencing*) guna mencegah kompilasi melingkar (*Circular Dependencies*).

| Modul Pengguna (Consumer) | Mengimpor / Bergantung Pada (Dependency) | Status Kepatuhan (Fitness) |
| --- | --- | --- |
| **Domain Plugins** (Tender, RAB) | `Plugin SDK`, `AI SDK` (hanya via `/api`) | ✅ Patuh (No Kernel direct access) |
| **Gateway / SDK** | `AI Service Mesh` (`/mesh/data`) | ✅ Patuh |
| **AI Service Mesh** | `Cognitive OS`, `UnifiedManifestLoader`, `IEventBus` | ✅ Patuh |
| **Cognitive OS** | `Knowledge Platform`, `IEventBus` | ✅ Patuh |
| **Knowledge Platform** | `AI Platform Foundation`, `IEventStore` | ✅ Patuh |
| **Event Platform** | *Agnostic* (Murni antarmuka infrastruktur) | ✅ Patuh |

## Pelanggaran yang Dianulir (Red Flags)
Tindakan kompilasi otomatis (Linter) akan memblokir kondisi berikut:
- **Mesh** memanggil struktur *Domain Plugin* (Misalnya `TenderAnalysis`).
- **Cognitive OS** mengimpor implementasi fisik *EventStoreDB* daripada `IEventStore`.
- **Domain Plugins** langsung mengimpor memori dari `kernel/cognitive`.
