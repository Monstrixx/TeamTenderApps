# MTX-002: Compatibility Matrix

## Standardisasi Backward Compatibility
Penyusunan Kernel AI di Era-1 dirancang dengan tujuan agar pelanggan perusahaan besar (Enterprise) tak perlu mengkhawatirkan migrasi (*Breaking Changes*) secara dadakan. Segala modul yang memanfaatkan Kernel diwajibkan untuk merepresentasikan level dukungan rilis minimum.

## Matriks Kompatibilitas Sistem vs Komponen
| Komponen Eksternal | Kompatibel Sejak Versi Kernel | Versi Patahan (Breaking Version) | Keterangan Tambahan |
| --- | --- | --- | --- |
| **AI SDK** (Frontend) | `1.0.0` | `2.0` | Disesuaikan dengan batas *Fluent API*. |
| **Plugin SDK** (Backend) | `1.0.0` | `2.0` | Mengandalkan *Manifest* standar v1. |
| **Retrieval Platform** | `1.1` (Upcoming) | TBD | Saat ini sedang dikembangkan (Era-2). |
| **Agent Runtime** | `1.2` (Upcoming) | TBD | Menunggu *Retrieval Platform* rampung. |

## Aturan Semantic Versioning (SemVer)
AI Core Kernel secara mutlak dipayungi rilis berstandar:
- `v1.0.1` -> Mengindikasi (Patch). *Bugs* teratasi, kontrak tidak ada yang patah.
- `v1.1.0` -> Mengindikasi (Minor). Titik ekstensi (`Extension Point`) baru ditambahkan, kompatibilitas terjamin.
- `v2.0.0` -> Mengindikasi (Major). Transformasi drastis struktur *Event* / Arsitektur API. Mengakibatkan *Plugin SDK 1.0* patah dan butuh migrasi *Manifest*. Modifikasi ini diwajibkan melewati prosedur pengajuan *RFC-001*.
