# SEC-003: Agent Collaboration & Artifact Security

## Memory Isolation via Broker
Agent Runtime **dilarang** meninjau memori *Cognitive OS* secara frontal (Bypass). Pintu akses hanya terbuka via `MemoryBroker`.

## Artifact Vault
Setiap objek yang tercipta (misal: *Generated Proposal*) disuntikkan parameter otorisasi *workspace* pada `ArtifactRegistry`. 
Dilarang memberikan akses baca-tulis kepada Agen dengan `TenantID` di luar domain yang melahirkan agen tersebut.
