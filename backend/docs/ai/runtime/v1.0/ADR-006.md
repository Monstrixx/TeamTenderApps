# ADR-006: Stateful Agent Runtime Architecture

## Context
AI-07 mensyaratkan perubahan dari sistem reaktif (*Execution -> Result*) menjadi *Distributed Operating System*. Skalabilitas ribuan *Agent* membutuhkan arsitektur terdesentralisasi.

## Decision
1. **Actor Model**: Mengadopsi pola pengiriman pesan (*Message Passing*) via *Mailbox*. Agen berstatus dorman (tertidur) apabila antrean *Mailbox* kosong.
2. **Scheduler Lifecycle**: Agen berjalan di bawah restu *Runtime Scheduler* dengan ragam antrean (*Priority, Delayed, Retry, Waiting, Approval*).
3. **Capability Session**: Hasil komunikasi dengan luar (Mesh) disahkan ke dalam *Aggregate Root* guna menampung observasi perilaku eksternal, telemetri keterlambatan, hingga pencatatan *Side Effects*.
4. **Agent State**: `CREATED -> INITIALIZED -> READY -> PLANNING -> WAITING_APPROVAL -> EXECUTING -> OBSERVING -> REPLANNING -> COMPLETED -> ARCHIVED`

## Consequences
Agen tidak lagi memblokir sistem. Panggilan LLM (*Planning/Evaluation*) bisa ditangguhkan (*delayed*) saat kuota infrastruktur memuncak.
