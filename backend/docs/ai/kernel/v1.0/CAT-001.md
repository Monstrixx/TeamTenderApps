# CAT-001: Component Catalog

## Ringkasan Komponen Kernel
Dokumen ini merangkum *building blocks* dari AI Core Kernel beserta status siklus hidupnya. Lifecycle ini menentukan kelayakan komponen untuk dikonsumsi dalam pengembangan operasional di tingkat perusahaan.

## Siklus Hidup (Lifecycle) Komponen
- **Experimental**: Masih dalam tahap uji coba (R&D). Potensi dirombak.
- **Preview**: Tersedia untuk dicoba pada skala terbatas. API belum stabil.
- **Stable**: Siap dioperasikan secara komersial. Tidak dirombak tanpa RFC.
- **Deprecated**: Terjadwal untuk dihapus. Modul dilarang memakainya kembali.
- **Removed**: Dicabut dan dihancurkan dari Kernel.

## Katalog Komponen Aktif

### 1. Unified Manifest Loader
**Fungsi**: Titik tunggal masuknya penguraian spesifikasi *Capability, Workflow, Tool, Event,* dan *Policy* untuk dibaca sebagai aset operasional (*Runtime Assets*).
**Lifecycle**: Stable

### 2. Mesh Gateway
**Fungsi**: Fasad gerbang utama API. Menerima *AIRequest*, memastikan versioning, lalu meneruskan pergerakan ke lapis rute (*Router*).
**Lifecycle**: Stable

### 3. Middleware Pipeline
**Fungsi**: Inspektor terpusat untuk *Security & Policy*. Mengeksekusi urutan `validate -> auth -> isolation -> context -> route -> execute`.
**Lifecycle**: Stable

### 4. Context Composer
**Fungsi**: Peramu konteks asimilatif. Menyatukan data dari *Workspace, Knowledge*, dan riwayat *Memory*.
**Lifecycle**: Stable

### 5. AIKernelBootSequence
**Fungsi**: Pusat penyalaan sistem (`CREATED -> READY`).
**Lifecycle**: Stable

### 6. IEventStore & IEventBus
**Fungsi**: Titik transmisi asinkron utama. (Implementasinya bersifat sekunder).
**Lifecycle**: Stable

### 7. Replay Engine
**Fungsi**: Alat reka ulang sejarah (*Replayability*) secara mutlak.
**Lifecycle**: Stable

### 8. Projection Builder
**Fungsi**: Generator model kueri bagi *dashboard executive* untuk meretas pola CQRS dari Event Store.
**Lifecycle**: Preview (Belum diaplikasikan penuh secara horizontal).
